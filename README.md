# Kurs_TiMP_Monashenko
Данный код представляет собой сервер, который будет высчитывать произведение векторов, поступаемых ему от клиента. Вычисления возможны только в том случае, если пользователь авторизируется.
===============================================================

Краткий гайд по использованию программы:

_Шаг 1: сборка программы_
1. Для сборки и корректной работы программы необходимо установить
библиотеку OpenSSL (для вычисления хэша MD5).

sudo apt-get update
sudo apt-get install build-essential libssl-dev

2. В корневой директории проекта нужно вызвать make для сборки проекта. Собранный исполняемый файл будет размещён по пути bin/vcalc_server.

_Шаг 2: запуск программы_
1. Для начала необходимо создать тестовую БД для работы сервера.

echo "user:"P@ssW0rd" > vcalc.conf

2. После производится запуск самого сервера.

./bin/vcalc_server -d vcalc.conf -l vcalc.log -p 33333

_Интерфейс через командную строку_

Данный сервер работает со следующими операциями:
1. -h, --help 
Вывод справочной информации. 
Значение: отсутствует 
Умолчание: отсутствует
Пример использования: ./vcalc_server -h

2. -d, --db
Указание пути к текстовому файлу БД клиентов.
Значение: путь к файлу
Умолчание: /home/25pi208@ibst.psu/vcalc.conf
Пример использования: ./vcalc_server -d ./db.conf

3. -l, --log
Указание пути к файлу логов работы сервера.
Значение: путь к файлу
Умолчание: /home/25pi208@ibst.psu/vcalc.log
Пример использования: ./vcalc_server -l ./server.log

4. -p, --port
Указание номера TCP-порта для прослушивания входящих соединений.
Значение: целое число (порт)
Умолчание: 33333
Пример использования: ./vcalc_server -p 8000

_Шаг 3: Тестирование сервера через тест-клиентов_
Для успешного теста сервера, необходимо:
1. Чтобы он был запущен и слушал порт 33333.
2. Чтобы в файле БД (vcalc.conf) была запись user:"P@ssW0rd.
3. Чтобы использовался клиент, который посылает серверу векторы со значениями типа int16_t.
После этого производится запуск тестового клиента.

./client_int16 -H MD5 -S c

При успешном подключении клиент сначала вводит число векторв, а после элементы каждого вектора через пробел. Сервер считает и возвращает произведение элеметов каждого вектора.
